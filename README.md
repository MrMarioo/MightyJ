# MightyJ
 
A lightweight Java IDE built from scratch in modern Java.
 
MightyJ focuses on Java projects: a fast editor, syntax highlighting, code completion and diagnostics through the Language Server Protocol, Maven and Gradle support, and a built-in debugger based on the Java Debug Interface.
 
> 🚧 Work in progress.
 
## Tech stack
 
Java 25 · JavaFX · LSP4J · Java Debug Interface · JGit
